  project refs/table detail stays in the private memory notes.
- **First candidate = Mission Control → SQLite**: internal, server key only, no logins, ~3 files, no migrations;
  smallest blast radius to prove the checklist. Honest that it saves $0 by itself.
- **Money framing**: with HiddenBag + DailyAI frozen, the Pro base stays; the realistic saving this phase is
  ~$0–10/month (closing database B), so the plan says the near-term value is control, not money.
- **Hetzner**: no headroom for a database server (swap in use); self-hosted Postgres implies new spending → owner.
