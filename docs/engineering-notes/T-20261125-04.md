## Requirement
Found during the unattended E2E run: every open task must eventually get a run; a new DEPLOY task must not wait behind a
busy old task.

## Root cause
`decideRun` picked the oldest-created eligible task. `vc8a2c` stayed eligible all morning (each Muse post counts as new
feedback), so at 11:56:04Z it was picked again while the never-attempted DEPLOY task T-20261125-03 was open.

## Solution
Among eligible tasks, order by last attempt: never attempted first, then least recently attempted; ties keep
oldest-created first (stable sort over the already oldest-first list).

## Lessons learned
L-012: "oldest first" starves new work when old tasks keep receiving feedback. Prefer least-recently-attempted.
